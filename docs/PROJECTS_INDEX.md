## How to present Project 01 on the web portfolio

The Enterprise Network Lab is now treated as a **technical case study**, not just a Packet Tracer file. Its project page explains:

1. Network architecture
2. VLAN and IP addressing
3. Switching and Layer-3 routing
4. DHCP
5. DNS
6. Wireless integration
7. Guest Wi-Fi isolation
8. Testing and troubleshooting
9. Lessons learned
10. Next improvements

This makes the project useful to a recruiter even when they cannot open the `.pkt` file.
